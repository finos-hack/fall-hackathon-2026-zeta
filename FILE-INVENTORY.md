# File inventory

This file inventories the current project files and generated or ignored outputs. Run `git status` to see pending changes.

## Excluded: generated or ignored

| Path | Why it is not kept | How to rebuild it |
|---|---|---|
| `poc/tools/node_modules/`, `poc/hub-extensions/calm-views/node_modules/` | installed packages | `npm ci` in each folder |
| `poc/tools/dist/`, `poc/hub-extensions/calm-views/dist/` | compiled JavaScript | `npm run build` in each folder |
| `.local/keys/` | development keys for the local Hub, not for production | `make keys` |
| `.local/architecture-as-code-build/`, `.local/hub-source-base` | upstream clone and marker used by the Hub image build | `make hub-build` |
| `.local/hub-models.env` | Hub IDs of the four seeded models and ADR | `make seed` |
| `.local/multi-cloud-runway/`, `.local/multi-cloud-runway.zeta-source` | landing zone source clone and marker used by the importer | `make landingzone-source` |
| `poc/renders/` | generated SVG, Markdown, JSON and the gallery | `make render` and `make gallery` |
| `.DS_Store` | operating system file | not needed |

`poc/renders/` is ignored by Git. Use `make render` and `make gallery` to regenerate its contents.

### Where the POC screen text lives

The POC screen has no separate Markdown file. The function `pocScreen` in `poc/hub-extensions/calm-views/src/poc.ts` builds the whole screen as one Markdown block. The Hub shows the block at `/extensions/calm-views/poc`. The function reads the model counts and view count from the repository files. It falls back to fixed model counts when a model file is missing.

- The optional custom Hub build uses the pinned source and local UI patches.
- The latest `make check` passes with the ZETA model, views and ADR changes.
